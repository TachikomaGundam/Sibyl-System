# release packet — v1.5.0

Owner-ordered evolution round (2026-10-24: 继续进化 per HANDOFF-SIBYL-20261023.md §3).
The whole six-item third-party-report queue landed in one wheel, one law each:

- **Input law on both probes; SSRF egress gate on the time probe.**
  `sibyl_time_probe` JSON.parse'd `endpoints` straight into fetch fan-out and
  `sibyl_attribute` trusted `moves`/`roster` the same way. Now: bounded-array
  parsing + per-entry shape validators with named, entry-indexed INPUT
  rejections (both probes); and, on the time probe's egress path, a pure
  offline `classifyEgress` gate before any fetch — reserved/internal IPv4+IPv6 families
  (incl. mapped/compat/6to4 embedded v4 re-check, WHATWG-normalized encodings),
  single-label hosts, internal suffixes, non-http(s), userinfo, non-default
  ports — all refused by rule name. A blocked source is a failed receipt
  (blocked is never consent); all-blocked yields INSUFFICIENT-SOURCES with zero
  fetches. PURE cores untouched; execute bodies export test seams.
  `sibyl_attribute` is input law only — it performs zero network by construction.
- **Single-source collapse.** withTimeout (2 copies), the unknown-error renderer
  (3 copies with drift risk), DEFAULT_TIMEOUT_MS (3 copies behind a human parity
  comment) each have exactly one definition now (src/util.ts, src/options.ts).
- **Type-face honesty.** Both `as never` casts in the SDK adapter are gone: the
  delete/get seams now carry `query.directory` like create/prompt/messages — the
  casts had been masking the host's instance-scoped call contract from tsc.
- **Tag-body hygiene gate (the wheel's mirror law).** The v1.4.0 tag message
  carried one machine-local clone path onto the public remote (honestly kept,
  history unrewritten). The W4 hook now polices the pushed tag MESSAGE (it is a
  client-side per-clone hook — its bypass class is a named limitation in
  SECURITY.md): home-path and email shapes refuse by rule name; refusals never
  echo the offending line; the tagger field is exempt (registered identity
  law); lightweight tags exempt.
- **Community surface.** CHANGELOG.md (packets stay the single source),
  SECURITY.md (private-advisory disclosure, data-egress map, named limitations),
  Dependabot (npm + Actions, weekly). GitHub Releases lag (v1.0.2) is a human
  `gh` action, prescribed separately.
- **Coverage ratchet.** Offline floor via node 22 built-ins at lines 55 /
  branches 80 / functions 90 against the measured 57.91/84.56/93.32 baseline;
  named ruling: the door runs in CI, ship.sh keeps its five offline doors (the
  wheel runs ship several times per session; the tax stays off the local loop).

SSRF gate judges URL literal shapes; a public hostname resolving into internal
