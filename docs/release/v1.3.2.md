# release packet — v1.3.2

W1-v2: the convener-recusal law grows a content-lineage leg. Ballot 526d (the
effective review of the v1.3.1 wheel's own receipt) demonstrated the miss class:
an artifact can be authored by the convening chain under a different checkout
path and drafted through shell argv, and the path-equality scan reads such a
chain INDEPENDENT. The instrument must catch its own misses — this wheel turns
the registered gaps F-W1a/F-W1c into a detector.

## what ships

- src/independence.ts: sample verbatim 256-byte windows of a path artifact
  (>= 3 windows required for the leg to speak; up to 32 sampled evenly) and
  match them across the convener chain against write-tool content keys AND
  shell command argv. False-conviction gates: a part is credited only when its
  creation stamp predates the artifact's mtime (a later part can only have
  copied FROM the file — copying is not drafting), and conviction needs a 60%
  majority of the sampled windows (template boilerplate matches a few windows,
  never a majority). The clean verdict confesses the lineage tally (matched /
  sampled / post-mtime exclusions / timeless parts) on the receipt face.
- src/index.ts + src/engine/index.ts: the messages seam passes the creation
  timestamp through (the live store always carried it; the narrowed bag was
  stripping it — the very bug class this wheel hunts: the detector confessing
  '595 parts lacked timestamps' on first live fire, caught by the live proof,
  not by the unit mocks).
- e2e/w1v2-live-20261008.mjs: replays the 526d canonical case against the real
  engine store. Result: 18 of 21 windows matched, three cited sources in the
  convening chain => NOT-INDEPENDENT; the control artifact (release template)
  stays INDEPENDENT.
