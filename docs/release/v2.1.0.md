## Scope

- **Run-session reclaim (council H approve group, run
  `sibyl-20261114T101952Z-d820`, 2A/1R/0E/0M).** Every `sibyl_consult` close
  and swarm run close deletes the persona/child sessions the run itself
  created, through the engine's `session.delete` domain (client call, no
  direct store writes; the engine owns the message cascade). Created ids are
  tracked in-run; deletion is LIFO; the parent conversation is never in the
  delete set; `retainSessions: true` opts out. Receipt appears in tool output
  (`reclaim: deleted=N skipped=N failed=N`), in the run record, and in the
  run ledger. Failure to reclaim never flips a converged verdict (H1c).
  Live proof on opencode 2.2.7: council run `sibyl-20261116T062954Z-4fb9`
  closed `reclaim: deleted=3 skipped=0 failed=0`, isolated store retaining
  only the convener row.
- **Run-space co-location.** `SESSIONS.json`, `CHECKSUMS.txt`,
  `TERMINALS.txt` and the voter drafts are written inside the run space
  directory (code refs: `src/tools/reclaim.ts`, `src/tools/swarm.ts`);
  absolute v1 paths remain readable (fallback), so external consumers of
  the old layout are unaffected.
- **Frozen-set retention (H2).** `scripts/session-reap.mjs` gains
  `--dry-manifest` (classify once; the dry face and the apply face read the
  same frozen rows), an orphan guard, and `--promote-orphans` cascade-root
  mode. Motivation is a measured deviation: the P1 sweep's recompute-at-apply
  let one row cross the 7-day line in the 87 seconds between dry-run and
  apply (receipt: `.omo` evidence dir, operator-local; deviation restored
  same day from a same-day store copy).
- **Stale run-dir janitor (H3).** `scripts/gc-run-dirs.mjs` moves stale
  `/tmp/sibyl-run-*` directories to the archive store with a symlink guard;
  default is dry-run.
- **In-flight observability.** `scripts/run-progress.mjs` (read-only): run
  status, ballot files landed, elapsed; exposes stale `running` ledger rows
  as data. No writes.
- **Publish-gate fixes (landed on main pre-wheel):** `workflow_dispatch`
  republish reads pinned files; H1 causal tie fed by a wall-clock step;
  lease check accepts both documented version forms.
- **Evidence-locality restoration.** The operator evidence journal moved out
  of the tracked tree per `docs/release/TEMPLATE.md` (operator-local by
  design); residual named under Open limits.
- **Version note.** 2.1.0 doubles as the opencode plugin-cache key: the
  engine caches by `name@version`, so a distinct version is what forces a
  fresh copy instead of a stale cached 2.0.0 (root cause of the sentinel
  silence 2026-11-14, `deleted` receipts absent until cache key moved).
