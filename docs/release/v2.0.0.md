gate: PASS

## Scope

- **opencode 2.x platform (breaking).** The plugin ships as the V2
  definition `{ id: "sibyl-system", setup(ctx) }`; tools register through
  `ctx.tool.transform`, options arrive through the V2 `plugins` object form,
  the voter/system prompt split is bridged in `src/v2/adapter.ts`, and the
  bundle carries zero `@opencode` runtime imports. opencode 1.x is retired:
  the V1 export stopped loading under 2.2.7 (host log: SchemaError on the
  default export). Migration notes: `docs/V2-MIGRATION.md`.
- **Voter tool-gate enforcement point moves to execution time**
  (`ctx.tool.hook("execute.before")`): same law, stricter point — a
  disallowed tool is refused when called, not merely hidden from the list.
- **Session retention.** `scripts/session-reap.mjs` enumerates the 2.x
  `session_v2` store and deletes through `opencode session delete <id>`
  (engine-owned cascade); the legacy `serve` + `DELETE /session/:id` channel
  answers 405 under 2.x. Classifier and retention law unchanged.
- **Engine-default model parity.** An empty `modelPool` default skips
  `switchModel` (V1 parity); under 2.x a literal empty model ref persisted an
  unusable route and killed every voter (`provider.no-route`).
- **Idle-failure visibility.** A session reaching idle without an assistant
  message reports the engine idle outcome and provider error instead of a bare
  "no assistant message".
- **Hygiene (public repo).** Distribution guard extended with scratch/cache/
  editor-junk classes; internal working-trace references scrubbed from tracked
  docs; internal work-docs purged from the published git history (rewritten
  history force-pushed with owner approval; residuals named in Open limits);
  smoke kit rewritten to exercise the V2 shipped surface.
- **Lane role launch capability probe (`--pure`).** OpenCode 2.x `run` has no
  `--pure` flag; roles composed with it died at birth (PCB lane ticket
  20261108 addendum). `launchRole` now probes `"<bin>" run --help` once per
  binary and composes the flag only when advertised; an unanswering probe
  fails closed (`PURE-SUPPORT-UNVERIFIABLE`) rather than guessing the flag
  surface. Isolation unchanged — role-HOME pinning carries the guarantee.
  Acceptance receipts: live chamber `sibyl-20261112T134556Z-bfee` CONVERGED
  with empty role stderr, CHECKSUMS 21/21; V1-era bins keep byte-identical
  argv; +4 tests ship with the release.
- **Carried release-law changes committed after v1.6.5 but not yet recorded in
  a CHANGELOG entry (now covered here and in CHANGELOG [2.0.0]):** the W5
  pre-push hook law (release tags only after the commit lands on remote main),
  the H1 release-day auto-witness (publish waits for the audit its own tag
  triggered), the Chinese README + zero-CJK English README, the lane
  fix that keeps a masking dir from killing the lane binary, the border-gate
  header promotion DRAFT -> owner-signed (d53ded4), and the de-machining of
  the two fixable H4 border findings (a03cefc).
