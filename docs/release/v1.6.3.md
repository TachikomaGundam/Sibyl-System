# Release v1.6.3 — 2026-11-07

Security and reliability patch for isolated chamber roles. This release adds
an opt-in credential proxy so a role receives a scoped relay token instead of
an upstream provider key or a copy of the host OpenCode configuration.

## Contents

- Credential relay: loopback-only binding, provider allow-list, scoped role
  tokens, per-role request quota, closed OpenAI-compatible endpoint grammar,
  redirect refusal, and sanitized request receipts.
- Role containment: minimal child environment; isolated user, PID, IPC, UTS,
  and cgroup namespaces; fresh procfs; agent-controlled shell and web tools
  denied. Model traffic remains available only through the configured relay.
- Reliability: failed Swarm draft writes cannot yield approval; repeated CLI
  scenarios retain order; invalid launch inputs clean their temporary run dirs.
- Documentation: credential-proxy configuration, migration procedure, and
  explicit residual-boundary disclosure.
